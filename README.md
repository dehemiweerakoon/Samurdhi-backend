# Samurdhi Backend

A simple Node.js + Express backend project scaffolded for this workspace.

## Getting started

1. Install dependencies:
   npm install
2. Start the server:
   npm start
3. For development mode:
   npm run dev

The app runs on the default port `3000` unless `PORT` is set in an environment variable.

## Routes

- `GET /` → project welcome message
- `GET /health` → health check response
